# charles-github-intro

> A structured index of my GitHub repositories — what each one is for, what lives inside, and how to navigate my work.

---

## About

This repo is the entry point to my GitHub profile. I maintain seven repositories, each scoped to a specific purpose. If you're looking for a project, template, or component, this guide will point you to the right place.

---

## Repository Index

---

### [`charles-web-lab`](https://github.com/ITechDummvry5/charles-web-lab)
> Experiments, UI components, landing page clones, and development resources.

A workspace for testing ideas and building UI experiments. Projects here range from landing page clones to interactive 3D scenes.

**What makes this unique**
This is for **clones and copies** — rebuilding something that already exists to study how it works. If you're cloning an Apple Store page or copying a UI to understand its structure, it goes here. Not for original designs, not for polished work.

**Examples**
- Apple Store Landing Page Clone
- Animated Login Form
- Three.js 3D Car Viewer
- Dark/Light Theme Switcher
- CSS Animation Experiments

---

### [`charles-code-vault`](https://github.com/ITechDummvry5/charles-code-vault)
> A collection of code snippets, templates, frameworks, and web development assets.

Reusable code ready to drop into any project. Focused on utility — boilerplates, component libraries, and helper functions.

**What makes this unique**
This is for **reusable pieces**, not full projects. Nothing here is a complete app — everything is a fragment meant to be copied and used elsewhere. If you find yourself writing the same modal or form validation again, the finished version lives here.

**Examples**
- Bootstrap Admin Dashboard Template
- JavaScript Utility Functions
- Reusable Modal Component
- Authentication Boilerplate
- Form Validation Library

---

### [`charles-dev-collection`](https://github.com/ITechDummvry5/charles-dev-collection)
> Frontend-only complete web applications — no backend, no database.

Complete, standalone projects built with HTML, CSS, and JavaScript. Each app runs entirely in the browser.

**What makes this unique**
This is for **complete frontend apps** — projects with a clear purpose that are fully finished. No server, no database, no backend. If it needs a backend to work, it goes in `charles-codebase` instead. If it's unfinished or experimental, it goes in `charles-playground`.

**Examples**
- To-Do App
- Weather Dashboard
- Expense Tracker
- Scholarship Finder (ACADLINK)
- Calculator App

---

### [`charles-playground`](https://github.com/ITechDummvry5/charles-playground)
> Building, testing, and exploring ideas in web development and design.

A scratchpad for trying things out. Work-in-progress is expected and normal here.

**What makes this unique**
This is for **experiments with no deadline** — things you're building just to see if you can. It doesn't need to be finished, polished, or practical. If you saw a cool effect online and want to try recreating it, it starts here. Once it becomes a real project it moves somewhere else.

**Examples**
- Mouse Trail Effect
- Particle Background
- GSAP Scroll Animations
- Canvas Drawing App
- Typewriter Text Effect
- Dark Mode Toggle Animation
- WebGL Shader Test
- AI UI Concept Mockups

---

### [`charles-studio`](https://github.com/ITechDummvry5/charles-studio)
> Creative web projects, UI/UX concepts, landing pages, and interactive experiences.

Polished, production-quality UI work. Landing pages, product showcases, and portfolio-grade builds.

**What makes this unique**
This is for **original designs built to impress** — something you'd show a client or put in your portfolio. Not clones, not experiments, not half-finished work. Every project here should look like it could go live tomorrow. If it's a landing page clone, it goes in `charles-web-lab`. If it's still being tested, it goes in `charles-playground`.

**Examples**
- Luxury Tech Store
- iPhone 17 Product Showcase
- Portfolio Website
- SaaS Landing Page
- Agency Website Design

---

### [`charles-codebase`](https://github.com/ITechDummvry5/charles-codebase)
> Full-stack projects with a backend — PHP, Node.js, and database-driven applications.

Projects here have a server, database, or backend logic. Organized by technology stack for long-term maintenance.

**What makes this unique**
This is the only repo with a **backend**. If a project needs a database, server-side logic, authentication with sessions, or an API — it belongs here. Pure frontend apps go in `charles-dev-collection` instead.

```
charles-codebase/
├── php-projects/
├── node-projects/
├── react-projects/
├── admin-dashboard/
├── authentication-system/
├── e-commerce/
├── components/
└── templates/
```

**Examples**
- Admin Dashboard (PHP + MySQL)
- E-Commerce UI (cart, orders, database)
- Authentication System (login, register, sessions)
- Car Rental System (CRUD + database)
- 3D Product Viewer (React + backend API)

---

### [`charles-tutorial-yt-course`](https://github.com/ITechDummvry5/charles-tutorial-yt-course)
> Practice builds and code from YouTube tutorials and online courses — organized by source.

A dedicated repo for learning. Each folder maps to a YouTube channel or online course. Code is written along with the tutorial, not copied.

**What makes this unique**
This is the only repo for **guided learning** — code written while following someone else's tutorial or course. Nothing here is an original project. If a tutorial inspires you to build your own version from scratch, that original build goes in another repo, not here.

```
charles-tutorial-yt-course/
├── youtube/
│   ├── traversy-media/
│   ├── kevin-powell/
│   ├── fireship/
│   └── the-net-ninja/
└── courses/
    ├── udemy-[course-title]/
    ├── freecodecamp-[topic]/
    └── scrimba-[course-title]/
```

**Examples**
- HTML & CSS Crash Course (Traversy Media)
- CSS Grid & Flexbox (Kevin Powell)
- JavaScript 30 (freeCodeCamp)
- React Course (Udemy)
- Node.js Fundamentals (The Net Ninja)
